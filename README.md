### 🔍 [Fake News Detection — Explainable Machine Learning](https://github.com/Taiye03/fake-news-det-project)

A machine learning research project investigating classification performance, model generalization, and shortcut learning across different datasets.

- Evaluated classification models using the ISOT and LIAR datasets.
- Observed approximately **99% accuracy on ISOT** compared with **62% on LIAR**.
- Applied LIME to investigate model predictions and potential shortcut behavior.
- Explored why high classification accuracy does not necessarily indicate reliable generalization.

**Technologies:** `Python` `Machine Learning` `LIME` `Data Analysis`
